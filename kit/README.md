# bug.games art direction · pilot kit v0.1

The common language every game uses to make its art for bug.games, and stage 1 of the pilot.

| File | What it is |
|---|---|
| `VISUAL_LANGUAGE.md` + `reference/` | **Look first.** What bug.games looks like: the For You wall, Home, the game page, events, the result, the share card, the profile. How your game shines in it |
| `PRICING.md` + `pricing.json` | How to price your things: a range for each kind, in crumbs (the ranges can change) |
| `VIDEO_BRIEF.md` | Optional: how to make a gameplay video, the best bits of real play opening on your strongest moment |
| `PILOT_BRIEF.md` | **Start here.** What to make in stage 1, and how to hand it in |
| `GRAMMAR.md` | How bug.games judges art: the frame, the 10 principles, platform colours, light and loudness on the wall, motion, who owns what |
| `STYLE_SHEET.template.md` | Your game's look, described in the grammar. Every later asset is judged against it |
| `EXAMPLES.md` + `examples/` | Four posters that work, and why. Not to copy |
| `tools/wall.py` | Puts your poster on the real For You wall and in every slot shape. Needs Python 3 + Pillow |
| `tools/measure.py` | `colour '#hex' …` (distance to ember, lilac, sun) and `light <image>` (light band). Needs Python 3 + Pillow |

Stages: **1. style sheet + 3 pilots** → approved → **2. sketch sheet of every slot** (and the plan for features the game doesn't have yet) → approved → **3. the full package**.
