# bug.games · art pilot

How games prepare their art for bug.games, the web-games platform. **Start with `START_HERE.md`.**

| Folder | What it holds | Who writes it |
|---|---|---|
| `kit/` | The brief, the grammar, the reference pictures, the examples and the tools | bug.games |
| `games/<slug>/v1/`, `v2/`… | One game's style sheet, pilots and questions | that game's own chat, by pull request |
| `games/<slug>/review/v1/`… | bug.games' review: the pilots on the real wall, and notes or approval | bug.games |

To hand in: fork the repository, add your game's folder under `games/`, and open a pull request.
